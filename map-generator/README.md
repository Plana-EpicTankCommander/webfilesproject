# 地图编辑器

一个完全在浏览器本地运行的地图编辑工具：载入真实底图后，点选省份把它划入当前国家，
地图会即时重算国界、颜色和标签，并导出可直接给网站插件使用的完整地图 JSON。

## 打开

```bash
npm run dev
# http://localhost:5173/map-generator/
```

> 这是本地开发工具，不进入 `npm run build`，不会生成 `dist/map-generator/`，也不会部署到线上。

## 用法

1. 默认加载「世界」底图；也可以在顶部切换到「东亚」，或点「选择本地地图 JSON」。
2. 在左侧选择一个国家作为当前国家；也可以添加一个新国家。
3. 点击右侧地图上的省份，把它划入当前国家。
   - 省份颜色会换成当前国家的颜色
   - 国界、海岸线、国家包围盒和标签会自动重算
   - 省份编号会自动改成当前国家代码 + 三位序号，例如 `TST001`
   - 把「点击模式」切到「删除」后，点击地块会把它从所属国家移除；「撤销删除」可恢复上一次删除
   - 「删除国家 tag（含全部地块）」会删除当前国家及其所有地块，操作前会弹窗确认，也可撤销
4. 修改国家名称、颜色；地图和导出的数据同步更新。
5. 国家行右侧的眼睛图标，或「当前国家」里的「显示在地图上」开关，可以把国家从地图上隐藏。
   - 隐藏后不渲染它的领土，也不写进导出的 JSON
   - 再点一次恢复显示
   - 隐藏 / 显示后，地图会自动缩放到当前所有可见国家；只留日本时会直接放大到日本
6. 点「批量操作」进入多选模式，可以勾选多个国家：
   - 批量显示 / 隐藏
   - 批量设置国家颜色（该国的行政区会跟着换色）
   - 全选当前搜索结果 / 清除选择
7. 「省份色差」开关默认关闭，同一国家所有省份使用国家纯色。
   - 打开后，每个省份会在国家颜色上做约 ±6% 的明度浮动，形成省份色块
   - 切换开关会立即重算所有已显示省份的颜色
8. 点「下载 JSON」或「复制 JSON」。

## 导出格式

导出的是完整 `hoi4-map` JSON，与 `world-map.json` / `east-asia-map.json` 结构一致：

- `countries[]`：国家代码、名称、颜色、`bbox`、`label`、`area`、国界弧段、下辖行政区
- `divisions[]`：行政区 ID、所属国家、名称、颜色、`polygons`
- `arcs` / `coast` / `borders` / `graticule`：边界几何
- `meta.width` / `meta.height`：底图尺寸

导出文件可以直接上传到：

```text
sth_ineed/maps/<id>-map.json
```

文章里写：

```markdown
[map:<id>;h:560;title:标题]
```

## 说明

- 底图来自内容仓库的 `sth_ineed/maps/`，也可以使用本地文件。
- 世界底图有 4,928 个行政区，其中中国大陆 366 个市级 / 省直辖县级单元，每次改归属都会重建渲染数据，操作会比东亚底图慢一些。
- 编辑只在浏览器内进行，不会上传或保存到服务器。
- 新增国家一开始没有省份，点击地图省份后才会拥有领土。
