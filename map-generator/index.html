这份 JSON 包含什么？

只包含国家、行政区、编号和颜色，不包含边界坐标。格式是 hoi4-map-data；如果要用现有地图插件渲染，需要再把 countries / divisions 与某个底图的几何数据合并。

纯本地工具，不会上传或保存任何输入。 修改会即时反映在右侧 JSON 预览中。
